## 记法说明

- **E-R 图（Chen 记法）**：蓝色矩形 = 实体，黄色菱形 = 关系，边上 `1`/`N`/`M` = 基数；局部图实体框内列出关键属性，主键加下划线。
- **关系模式图**：每张表为一个框，深色表头 + 字段列表（PK 标下划线，FK 标注），表间连线标外键列与 `1—N` 基数。
- 全局 E-R 图省略了 8 条 "用户拥有 X" 的归属线，因所有业务表均通过 `user_id` 隔离，图注已说明；归属关系在局部 E-R 图中体现。

## 重新渲染

```powershell
# 先装 Graphviz（仅一次）
winget install --id Graphviz.Graphviz
# 在本目录执行
pwsh -File render.ps1
```

PNG 为 150 DPI 高清，插入 Word 后即使缩放到页宽仍清晰。如需更高清晰度，改 `render.ps1` 里的 `-Gdpi=150` 为 `200` 或 `300`。

## 插入 Word 建议

- 全局 E-R 图、关系模式图：宽高比接近 A4，可直接插入正文，单独占一行。
- 局部 E-R 图为横向（LR）布局、较宽，建议：插入后设为"嵌入型"并占满页宽；若字仍偏小，可把该图放到**横向页面**（页面布局 → 纵向起始页 → 该页改横向），或拆成两段。
- 优先插入 **SVG**（Word 支持矢量，任意缩放不糊）；若 Word 版本对 SVG 兼容不好，再用 PNG。
