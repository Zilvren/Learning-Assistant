# 错题追踪器

一个 Web 版错题管理与学习辅助工具，支持 Markdown + LaTeX 编辑、OCR 图片识别、标签分类及错题本打印导出。

## ✨ 功能

### 错题管理
- **自定义标题** — 每道错题可编辑独立标题，列表一目了然
- **Markdown + LaTeX 编辑器** — 支持加粗、斜体、删除线、代码块、行内公式、公式块、链接、图片
- **公式工具** — 内置 `\xcancel` 公式删除线按钮，选中公式一键加叉号
- **图片折叠** — OCR 生成的 base64 大图可一键折叠/展开，编辑不卡顿
- **实时预览** — 左右分栏，输入即时渲染

### 标签系统
- **题目标签** — 空格分隔多标签，如 `曲线积分 格林公式 高数`
- **错因标签** — 独立错因标签，如 `概念混淆 计算错误`
- **标签搜索** — 按题目标签 / 错因标签分别筛选，模糊匹配
- **标签筛选** — 搜索下拉可选：全部 / 题目 / 题目标签 / 错因标签
- **点击筛选** — 表格中标签 chip 可点击直接筛选

### OCR 识别
- **拍照转文字** — 基于 MinerU API v4，拍照/截图自动识别为 Markdown
- **公式 + 图片内嵌** — 自动提取图片并内嵌为 base64，无需外部文件
- **Ctrl+V 粘贴** — 截图后直接粘贴到编辑器
- **光标处插入** — 多次 OCR 自动追加到光标位置，不覆盖已有内容

### 学习辅助
- **错题本导出** — 一键打开浏览器打印导出，保留 Markdown、公式和图片排版
- **每日推送** — 基于当前科目和错题数据生成复习建议

### 科目管理
- **自定义科目** — 支持增删科目，完全自定义
- **科目筛选** — 列表按科目分类，chip 切换

## 🚀 快速开始

### 方式一：运行 EXE（推荐）

下载 [Releases](../../releases) 中的 `Tracker.zip`，解压运行 `Tracker.exe`，自动打开浏览器。

> EXE 会在同级目录创建 `data/` 文件夹存放数据，删除即重置。完全离线可用。

### 方式二：源码运行

右键 `start.ps1` → 使用 PowerShell 运行，自动安装依赖、构建前端并启动服务。浏览器打开 http://127.0.0.1:8000

> 需要已安装 Python 3.10+ 和 Node.js。
> 源码入口统一为 Web 版：`run.py` / `backend/api.py` + Vue 前端。


## 🔧 MinerU OCR 配置

1. 注册 [MinerU](https://mineru.net) 获取 API Token
2. 在应用页面打开 ⚙️ 设置 → 粘贴 Token → 点保存
3. 添加错题时点击 📷 OCR 导入，或直接 Ctrl+V 粘贴截图

## 🛠 技术栈

| 层 | 技术 |
|---|------|
| 前端 | Vue 3 + Vite |
| 后端 | Python FastAPI + Uvicorn |
| 公式渲染 | KaTeX |
| Markdown | markdown-it |
| OCR | MinerU API v4 |
| 打包 | PyInstaller |
